# Mert's Cobalt NetStalker

Minimalist, zero-interaction, real-time desktop network & ping monitor HUD built with PySide6.

## Features

- Real-time network and ping monitoring on your desktop
- Zero interaction: it just sits there and shows you what you need
- Lightweight: stays around 0.1% CPU and ~43 MB RAM while running
- [add anything else it does]

## Requirements

- Windows
- Python 3.x

## Download

Grab the latest `.exe` from the [Releases](https://github.com/mertbyte/Mert-Cobalt-Net-Stalker/releases/latest) page and double-click it.

## Run from source

Requires Python 3.x.

```bash
git clone https://github.com/mertbyte/Mert-Cobalt-Net-Stalker.git
cd Mert-Cobalt-Net-Stalker
pip install PySide6 psutil
python net_stalker.py
```
